# استبيان مستحضرات التجميل بالقليعة

استمارة عربية من صفحة واحدة، مع تخزين الإجابات في قاعدة SQLite على الخادم. يتطلب التشغيل Node.js 22.13 أو أحدث. يستخدم التطبيق الوحدات المدمجة في Node.js.

## التشغيل المحلي

```powershell
npm.cmd start
```

افتح [الاستبيان](http://127.0.0.1:3000/) أو [صفحة صاحب المتجر](http://127.0.0.1:3000/owner). اسم مستخدم المالك هو `owner`. عند التشغيل الأول يُنشئ التطبيق كلمة مرور عشوائية في `data/owner-password.txt` ما لم يكن المتغير `OWNER_PASSWORD` مضبوطًا. تُحفظ الإجابات في `data/survey.sqlite`. لعرض الإجابات أو تنزيلها بصيغة CSV بترميز UTF-8، افتح صفحة المالك وأدخل بياناته في نافذة تسجيل الدخول التي يعرضها المتصفح.

## التشغيل على خادم

شغّل نسخة واحدة من التطبيق خلف HTTPS ووصلها بمجلد دائم يملك حساب الخدمة صلاحية الكتابة فيه. عيّن `DATA_DIR` إلى هذا المجلد، واضبط `OWNER_PASSWORD` في إعدادات الأسرار. يمكن ضبط `HOST` و`PORT` حسب إعدادات الاستضافة. عنوان الاستماع الافتراضي محلي. شارك الرابط العام للاستبيان وحده مع الطالبات.

قبل فتح الاستبيان للجمهور، حدّد حساب المالك وفترة الجمع وموعد حذف البيانات، وراجع سجلات الاستضافة. عند انتهاء الجمع، أعد تشغيل الخادم مع `COLLECTION_OPEN=false` لإيقاف استقبال الإجابات مع استمرار وصول المالك إلى التصدير. عند انقضاء مدة الاحتفاظ، أوقف الخدمة واحذف قاعدة بيانات الاستبيان وملفات SQLite المصاحبة والنسخ المصدّرة والاحتياطية وفق الإجراء المتفق عليه.

## الاختبار

```powershell
npm.cmd test
```

تستخدم اختبارات الخادم قاعدة مؤقتة منفصلة لفحص التحقق، وتزامن الإرسال، واستمرار الردود بعد إعادة التشغيل، وصلاحيات الاطلاع، وتصدير العربية.
